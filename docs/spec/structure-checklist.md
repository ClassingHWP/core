# 한글 구조 체크리스트

HWP와 HWPX는 같은 `Document`로 읽는다. `chwp-dump json`은 그 모델의 보기이고, 쪽 그림은 JSON을 다시 파싱하지 않고 같은 모델을 조판한 뒤 그린다. 형식마다 그리는 길을 만들지 않는다. 화면에 없으면 파서가 그 필드를 안 채운 것이다.

체크는 2026-10-03 코드 기준이다. 두 파서가 같은 필드에 넣고, 쪽 그림이 그 필드를 쓸 때만 `[x]`다. 한쪽만 읽거나 모델에만 있으면 `[ ]`이고, 괄호에 어디까지인지 적는다.

조판 식의 샘플 대조는 [implementation-status.md](implementation-status.md)에 있다. 이 문서는 구조 항목만 본다.

## 파일

- [x] HWP 5.x CFB, 레코드, raw deflate
- [x] HWP 암호, DRM, 공인인증서 암호화는 본문을 읽지 않고 오류
- [x] HWPX ZIP, `version.xml`, `content.hpf`, `header.xml`, `section{N}.xml`
- [x] 문서 요약. 제목, 지은이, 주제, 설명, 키워드, 만든 시각, 고친 시각
- [x] 미리보기 텍스트 `PrvText`
- [ ] 배포용 문서 본문 복호 (HWP는 배포용이라고만 알리고 본문을 건너뜀)
- [ ] HWP 미리보기 이미지, 스크립트, XML 템플릿, 문서 이력, 문서 옵션, 참고문헌
- [ ] HWPX `settings.xml` 캐럿 위치, 금칙 문자 목록
- [ ] HWPML(`.hml`), HWP 3.x

- [x] 대체 글꼴 이름. 글리프가 없을 때 그 이름으로 다시 찾음

- [x] 단색 면, 두 색 그러데이션과 각도
- [x] 그림 채우기. 바둑판, 크기에 맞춤, 가운데
- [ ] 대각선, 사선, 무늬(hatch), 입체, 그림자, 중심선, 셀 분리선
- [ ] 그러데이션 종류, 중심, 단계, 셋 이상의 색, 투명도
